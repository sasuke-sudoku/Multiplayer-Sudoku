# 企業・人物紹介ショートの作り方

プロジェクト: `trend-shorts/`（Remotion）。1本の動画 = `trend-shorts/episodes/<slug>.json` 1ファイル。
見本は `trend-shorts/episodes/polsia.json`。**デザインやコードは原則いじらず、エピソードJSONだけ書く。**

## 手順

1. **題材を決める**（指定がなければ探す）
   - 海外または日本で、いま話題の企業・人物。数字（売上・顧客数・評価額など）で驚きがあり、
     「光と影」（課題・失敗・リスク）も語れるもの。
   - WebSearch で一次報道（WSJ、Bloomberg、日経など）と本人・会社の発信を確認する。
   - 数字は必ず意味を区別する：売上実績／売上見込み／年換算（ARR）／企業評価額／利益。
     本人発表の数字は「本人発表」「報道によると」と書く。換算レートを決めて（例: 1ドル=150円）概要欄に書く。
   - 確認できない話は断定しない。一般論にするか削る。

2. **台本を書く**（`episodes/<slug>.json`、構成は見本と同じ7シーン・14行）
   | scene | 役割 | 行数 |
   |---|---|---|
   | hook | 驚きの数字3つ＋一言 | 2 |
   | who | 人物プロフィール＋過去（挫折など） | 2 |
   | launch | 会社・サービスの登場と中身 | 2 |
   | growth | 成長の数字（メイン1つ＋カード2つ） | 2 |
   | how | 仕組み（4つの要素）＋決め台詞 | 2 |
   | shadow | 課題・リスク → その後 | 2 |
   | outro | 視聴者への問いかけ＋チャンネル登録 | 2 |
   - 各行: `text`（字幕。`\n` で改行、1行15文字以内）、`reading`（ナレーション用。漢字かな交じりで自然な文、
     英語の固有名詞はカタカナ）、`highlight`（黄色マーカーにする語。`text` に含まれる文字列、改行をまたがない）。
   - `visuals` は各シーンの画面上の文字（カード・数値・ラベル）。数値は "約375億円" のように書くとカウントアップする。
     `tone: "red"` で赤系カード（注意・マイナス情報）。
   - `title` は「？」で2行に分かれる（1行目＝疑問、2行目＝青字）。各行15文字以内。
   - `description` は概要欄の文章（数字の注意書き・出典・ハッシュタグ）。VOICEVOXクレジットは自動で足される。
   - 合計55秒前後が目安。長ければ文を削る（`voice.speed` は1.15のまま）。

3. **画像**（任意）: `public/images/<slug>/` に置き、`images.founder`（顔写真・正方形）、`images.logo`、
   `images.site`（サイトのスクショ・横長）にパスを書く。空欄ならアイコン/文字で代用。
   権利の確認できない報道写真は使わない（本人・会社の公開素材、自分で撮ったスクショ、利用許可のあるもの）。

4. **ビルド**
   ```bash
   cd trend-shorts
   bash scripts/setup.sh          # 初回のみ（npm / VOICEVOX のダウンロード）
   bash scripts/build.sh episodes/<slug>.json
   ```
   出力: `out/<slug>.mp4`、`out/<slug>-check.png`（各行の終わりの静止画一覧）、`out/<slug>-description.txt`。

5. **チェック**: `out/<slug>-check.png` を開いて、文字のはみ出し・重なり・折り返しを確認。
   はみ出していたら `text` に `\n` を入れる／文言を短くする → 再ビルド。

6. **納品**: 動画・概要欄テキストをユーザーに渡し、数字の根拠（出典URL）と未確認の点を必ず伝える。

## 注意
- 声: VOICEVOX:青山龍星（vvm 15, styleId 13）。他の声は `voice` を変更し `setup.sh <vvm番号>` で取得。
  青山龍星は企業が関わる利用では事前確認が必要。クレジット表記は必須（概要欄）。
- 背景は白・グラデーションなし・出典は画面に出さず概要欄、がこのチャンネルの方針。
- ネットワークが制限された環境では Remotion が Chromium を落とせないので、`build.sh` は
  `/opt/pw-browsers` のChromiumか `REMOTION_BROWSER` を使う。VOICEVOX は GitHub Releases から取得する。
