# 夕凪通り（ゆうなぎどおり）— 妖怪ウォッチ風 昭和ノスタルジー フィールドBGM

『妖怪ウォッチ2』の「桜町」（作曲：西郷憲一郎）の分析をもとに、**設計思想だけを参考にして作ったオリジナル曲**です。
原曲のメロディーやコード進行の書き起こしは使っていません。

| ファイル | 内容 |
| --- | --- |
| `yunagi-dori_full.mp3` | 試聴用（ループ2周＋フェードアウト、約3分50秒） |
| `yunagi-dori_loop.ogg` | ゲーム用の継ぎ目なしループ（110.8秒）。MP3は先頭に無音が入るためOGG |
| `yunagi-dori.mid` | DAW取り込み用MIDI（リコーダー／クラリネット／ギター／ピアノ／ベース／弦楽／ヴァイオリン／アコーディオン／鉄琴／打楽器） |
| `make_bgm.py` | 音源を生成するスクリプト（numpyのみ。`python3 make_bgm.py` で再生成） |

## 楽曲データ

- 調：Cメジャー　テンポ：78 BPM　拍子：4/4　全36小節
- 構成：イントロ(4) → A(8) → A'(8) → B(8) → A''(8) → イントロへループ

## 「桜町」の分析から取り入れた要素

| 分析で挙げた要素 | この曲での実装 |
| --- | --- |
| 音色で時代を語らせる | 主旋律は**アルトリコーダー**風。倍音の少ない柔らかな音に、タンギングの“チフ”（発音時の息の雑音）とごく浅いビブラートを加え、学校の音楽室のような素朴さを出した。伴奏のアコーディオンは倍音を減らし音量も下げて、オルガンっぽさを抑えている（複音ハーモニカ版の音源 `harmonica()` もスクリプトに残してある） |
| 口ずさめる旋律と余白 | ド・レ・ミ・ソ・ラ中心の**ヨナ抜き音階**で動機を作り、フレーズの終わりには必ず休符（呼吸）を置いた |
| ベースの順次下降 | A部の冒頭を **F → C/E → Dm7 → C**（ファ→ミ→レ→ド）にし、ルート→5度→経過音のウッドベースで流れを作った |
| 明るさの中の一瞬の陰り（借用和音） | A部6小節目の **Fm**（旋律にA♭）、A'/B部の **Fm6**、イントロの **A♭maj7** で、短調に転じずに切なさだけを差し込む |
| 探索の邪魔をしない時間感覚 | 78 BPM、伴奏はギターの8分アルペジオとシェイカー程度。アクセントの強い楽器は使わない |
| 長時間聴ける構成 | 編成を段階的に厚くする（下の表）。リバーブの余韻をループ先頭に折り返して**継ぎ目なし**に |
| ライトモティーフとしての再利用 | イントロの鉄琴が主題の頭を予告する。同じ動機を、テンポやコードを変えればイベント曲・戦闘曲に転用できる |

## 調整したい場合

`make_bgm.py` の冒頭にある `MEL_A` / `MEL_A2` / `MEL_B`（旋律）や `A` / `B`（コード）を書き換えて再実行してください。
音色を本格的にしたい場合は、`yunagi-dori.mid` をDAWに読み込み、リコーダー／ナイロンギター／ウッドベースの音源に差し替えるのがおすすめです。

## 編成（セクションごとの楽器）

| セクション | 演奏する楽器 |
| --- | --- |
| イントロ | ギター、ピアノ（全音符）、弦楽、鉄琴（主題の予告）、ベース（3小節目から） |
| A | ＋リコーダー（主旋律）、ピアノの裏打ち、バスドラム、シェイカー |
| A' | ＋クラリネット（長い音で3度・6度のハモり）、チェロ、アコーディオン、ブラシ |
| B | ＋クラリネットが全音でハモり、ヴァイオリン、鉄琴、タンバリン、ウッドブロック、バスドラム2つ打ち |
| A'' | 全楽器＋鉄琴が旋律をオクターブ上で重ねる |

ベースが1・3拍目、ピアノが2・4拍目を弾く“ズン・チャッ”の伴奏が、昭和の街らしいのどかさを作っています。
